# Evidence Collection Standards

## Objective

Maintain consistent evidence collection practices throughout investigations.

## Evidence Types

- Screenshots
- URLs
- Domain Records
- Investigation Notes
- Timestamp Records

## Collection Principles

### Accuracy

Capture information exactly as observed.

### Completeness

Document all relevant findings.

### Traceability

Ensure findings can be independently verified.

### Consistency

Follow standard documentation procedures.

## Deliverables

- Evidence Package
- Investigation Record
- Supporting Documentation
