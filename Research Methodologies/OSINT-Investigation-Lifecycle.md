# OSINT Investigation Lifecycle

## Overview

A structured framework for collecting, validating, analyzing, and documenting publicly available information.

## Phase 1: Planning

Define:

* Investigation objective
* Scope
* Information requirements

## Phase 2: Collection

Gather information from publicly available sources.

Examples:

* Websites
* Search engines
* Public records
* Social platforms
* Domain information

## Phase 3: Verification

Validate collected information for accuracy and relevance.

## Phase 4: Analysis

Identify:

* Patterns
* Relationships
* Indicators
* Relevant findings

## Phase 5: Documentation

Prepare:

* Investigation reports
* Evidence records
* Intelligence summaries

## Phase 6: Reporting

Present findings in a clear and actionable format.

## Core Principles

* Accuracy
* Traceability
* Documentation
* Verification
* Objectivity
